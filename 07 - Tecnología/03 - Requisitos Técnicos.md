# Requisitos Técnicos

## Descripción de la sección

Define las condiciones técnicas necesarias para ejecutar y desarrollar el videojuego.

## Requisitos mínimos

| Componente        | Requisito mínimo                     |
| ----------------- | ------------------------------------- |
| Sistema operativo | Windows 11 de 64 bits                 |
| CPU               | Intel Core i5-4460 o AMD Ryzen 3 1200 |
| GPU               | pendiente                             |
| RAM               | 8 GB                                 |
| Almacenamiento    | 5 GB de espacio disponible            |
| Resolución       | 1280 × 720 píxeles (HD)             |
| Conexión         | No requiere conexión a Internet.     |


## Requisitos recomendados

| Componente        | Requisito recomendado                                       |
| ----------------- | ----------------------------------------------------------- |
| Sistema operativo | Windows 10/11 de 64 bits                                    |
| CPU               | Intel Core i5-10400 o AMD Ryzen 5 3600                      |
| GPU               | NVIDIA GTX 1660 Super (6 GB) o AMD Radeon RX 5600 XT (6 GB) |
| RAM               | 16 GB                                                       |
| Almacenamiento    | 5 GB de espacio disponible en SSD                           |
| Resolución       | 1920 × 1080 píxeles (Full HD)                             |
| Rendimiento       | 60 FPS                                                      |
| Conexión         | No requiere conexión a Internet.                           |

## Objetivos de rendimiento

**FPS objetivo:** 60 FPS a una resolución de 1920 × 1080 píxeles.

**Tiempo de carga objetivo:** Máximo 15 segundos para iniciar la partida y 5 segundos para reiniciar desde un checkpoint.

**Memoria máxima:** 8 GB de RAM durante la ejecución del videojuego.

## Restricciones

Documenta límites conocidos del proyecto.

* **Plataforma:** El videojuego estará disponible únicamente para PC con Windows.
* **Rendimiento:** Se establece un objetivo de 60 FPS a una resolución de 1920 × 1080 píxeles, dependiendo de las capacidades del equipo.
* **Hardware:** El rendimiento estará limitado por la capacidad de procesamiento, memoria RAM y tarjeta gráfica del equipo.
* **Controles:** Solo se utilizarán teclado y mouse, sin soporte para mandos ni reasignación de teclas.
* **Conectividad:** El videojuego funcionará sin conexión a Internet y no incluirá funciones en línea.
* **Jugabilidad:** La experiencia será individual, con progresión lineal y una duración estimada de 25 a 35 minutos.
* **Guardado:** El progreso se guardará automáticamente mediante checkpoints, sin ranuras de guardado adicionales.
* **Gráficos:** La calidad de los modelos 3D, texturas, iluminación y efectos ambientales estará condicionada por los objetivos de rendimiento.
* **Compatibilidad:** No se contempla una versión para dispositivos móviles ni consolas.
