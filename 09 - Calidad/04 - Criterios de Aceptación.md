# Criterios de Aceptación

## Plantilla

### Característica: Progresión del jugador

**Dado que:** Vadrik comienza encerrado en la primera cabaña y debe avanzar hasta el laboratorio.

**Cuando:** El jugador explora los escenarios, encuentra las llaves, recoge los fusibles, activa los generadores e introduce el código correcto.

**Entonces:** Puede acceder a las distintas zonas, completar los objetivos y llegar al desenlace del videojuego.

### Característica: Sigilo y persecución

**Dado que:** La criatura mutante patrulla el bosque y representa una amenaza para Vadrik.

**Cuando:** El jugador es detectado o utiliza el sigilo para evitarla.

**Entonces:** La criatura mutante inicia la persecución al detectarlo, mientras que el jugador puede esconderse o huir para sobrevivir.

### Característica: Guardado y derrota

**Dado que:** El jugador ha alcanzado un checkpoint durante su recorrido.

**Cuando:** Es capturado por la criatura mutante o selecciona continuar una partida guardada.

**Entonces:** Regresa al último checkpoint con el progreso correspondiente.

## Criterios del proyecto

- [x] El bucle principal funciona.
- [x] Las condiciones de victoria y derrota funcionan.
- [x] El progreso puede guardarse.
- [x] Los sistemas principales están integrados.
- [x] Las pruebas críticas están aprobadas.
- [x] El rendimiento cumple el objetivo definido.
- [x] No existen errores bloqueantes conocidos.
