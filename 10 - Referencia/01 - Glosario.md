# Glosario

## 1. Términos técnicos

| Término    | Definición                                                                       |
| ----------- | --------------------------------------------------------------------------------- |
| Game Engine | Motor que proporciona las herramientas necesarias para desarrollar un videojuego. |
| Asset       | Recurso utilizado en el juego, como modelos, texturas, sonidos o animaciones.     |
| Mesh        | Estructura geométrica que forma un modelo tridimensional.                        |
| Texture     | Imagen aplicada a un modelo 3D para definir su apariencia.                        |
| Shader      | Programa que controla la representación visual de materiales e iluminación.     |
| Rigidbody   | Componente que permite aplicar físicas a los objetos.                            |
| Raycast     | Técnica que utiliza un rayo para detectar objetos o superficies.                 |
| Material    | Recurso que determina las propiedades visuales de una superficie.                 |

## 2. Términos de diseño y jugabilidad

| Término                   | Definición                                                                        |
| -------------------------- | ---------------------------------------------------------------------------------- |
| GDD (Game Design Document) | Documento que reúne el diseño y las especificaciones del videojuego.             |
| Gameplay                   | Conjunto de mecánicas y acciones que conforman la experiencia del jugador.        |
| HUD                        | Información que aparece en pantalla durante la partida.                           |
| UI                         | Elementos visuales que permiten interactuar con los sistemas del juego.            |
| NPC                        | Personaje que no es controlado directamente por el jugador.                        |
| Checkpoint                 | Punto de control que permite guardar y recuperar el progreso.                      |
| MVP                        | Versión mínima funcional que contiene las características esenciales del juego. |
| Vertical Slice             | Fragmento desarrollado que demuestra la calidad prevista para el producto final.   |

## 3. Términos del universo de Dark Mutant

| Término         | Definición                                                                                              |
| ---------------- | -------------------------------------------------------------------------------------------------------- |
| Vadrik Dsang     | Protagonista que investiga los acontecimientos relacionados con su hijo y el laboratorio.                |
| Jereth Dsang     | Hijo de Vadrik, sometido a los experimentos del Dr. Cooper.                                              |
| Dr. Cooper       | Científico responsable de los experimentos realizados en el laboratorio.                                |
| Criatura mutante | Resultado de los experimentos realizados sobre Jereth, sin conciencia humana.                            |
| Laboratorio      | Instalación donde se desarrollaron los experimentos y se descubre la verdad de los acontecimientos.     |
| Expedientes      | Documentos que contienen información sobre los experimentos, sus resultados y los sujetos involucrados. |
| Fusibles         | Componentes eléctricos necesarios para activar los generadores del laboratorio.                         |
| Generadores      | Equipos que permiten restablecer el suministro eléctrico del laboratorio.                               |

## Convenciones de nombres

| Término oficial  | Convención                                                                                                |
| ---------------- | --------------------------------------------------------------------------------------------------------- |
| Dark Mutant      | Nombre oficial del videojuego. Respetar las mayúsculas iniciales.                                         |
| Vadrik D.sang    | Nombre completo del protagonista.                                                                         |
| Jereth D.sang    | Nombre completo del hijo de Vadrik.                                                                       |
| Dr. Cooper       | Utilizar siempre «Cooper», nunca «Copper».                                                                |
| Criatura mutante | Utilizar este término para referirse a Jereth transformado, evitando «monstruo» o «mutante» por separado. |
